## Run

With [uv](https://docs.astral.sh/uv/); uvx installs the package and its runtime on first use:

```console
uvx codapact-ynab --help
uvx --refresh-package codapact-ynab codapact-ynab --version   # update to the latest
```

Requires Python 3.13 or newer.

## Credentials

Save once in the OS keyring with `uvx codapact-ynab auth login`, or set per shell:

- `bearer`: `YNAB_BEARER`. Create a personal access token in YNAB under Account Settings > Developer Settings (https://app.ynab.com/settings/developer). It grants full access to your budgets.

`<VAR>_COMMAND` runs a command that prints the secret (e.g. a password manager). `uvx codapact-ynab doctor` checks settings, credentials, and connectivity.

## Use

```console
uvx codapact-ynab plans list
uvx codapact-ynab accounts list -o table
uvx codapact-ynab transactions list --since-date 2026-01-01 --query 'data.transactions[].payee_name'
uvx codapact-ynab describe --brief   # every command, for scripts and agents
```

As a library:

```python
from codapact_ynab import Client

client = Client()
```

## Notes

`--plan-id` defaults to `last-used`. `--dry-run` prints the HTTP request without
sending it; commands that delete ask for confirmation (or `--yes`).

Upgrading from 0.2.0, where the command was `ynab`: a login saved with
`ynab auth login` and settings in `~/.config/ynab/` are picked up automatically.
`codapact-ynab` replaces `ynab-api-cli`, which is no longer maintained.

## Development

The code in `gen/python/` is generated by [Codapact](https://github.com/mikejhill/codapact). Do not edit it; regenerate instead:

```console
uvx codapact==0.17.3 sync --check                              # has the provider published a new contract?
uvx codapact==0.17.3 sync                                      # pull it into the pinned copy
uvx codapact==0.17.3 generate                                  # run where codapact.yaml is
uv run --directory gen/python pytest                           # offline: help, dry runs, scenarios
YNAB_E2E_LIVE=1 uv run --directory gen/python pytest -k live   # read-only calls to the real API
```
